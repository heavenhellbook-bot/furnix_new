# FURNIX TECH DATA — інтеграційний набір

## Що входить і що **не** входить

- `module-pack.json` / `.mjs`: **24 оригінальні параметричні шаблони FURNIX**, які інтегровані у `kitchen-core.mjs` і з'являються в каталозі після відкриття `index.html`. Це переважно прямокутні корпуси нестандартних розмірів, побудовані за демонстраційними формулами наявного ядра. **Не** копії бібліотек виробників і **не** перевірені виробничі конструкції.
- `materials.json`: 13 прикладів узагальнених записів матеріалів, без артикулів виробників і без підтверджених допусків.
- `edgebands.json`: 12 демонстраційних записів крайки без прив'язки до конкретних артикулів та технологій.
- `hardware.json`: покажчик офіційних CAD-каталогів чотирьох виробників, **без** їхніх креслень/присадки.
- `manufacturing-profiles.json`: порожні профілі ВІЯР, KRONAS та власного виробництва, де всі виробничі значення `null` до перевірки.
- `source-registry.json`: офіційні посилання, ліцензійні зауваження; посилання не є імпортованими CAD-файлами.
- `tech-library.mjs`: функції перевірки, пошуку, імпорту та блокування непідтверджених даних.
- `import_python.py`: приклад читання JSON бібліотек у Python-бекенді.

**Відсутні:** пропрієтарні CAD-бібліотеки Blum, Hettich, GRASS, Salice, повний код FreeCAD Woodworking, OpenCutList, промислові постпроцесори, підтверджені схеми присадки й профілі розкрою. Їх треба отримати відповідно до умов виробників і інтегрувати окремо після перевірки.

## Підключення до поточного FURNIX

Пакет інтегрований через assembly-adapter.mjs. У «Моя библиотека → Шаблоны Tech Library» доступні 42 шаблони (18 базових та 24 додаткові). Технічна бібліотека відкривається посиланням у верхній навігації. Не замінюйте поточний редактор файлами kitchen-core.mjs з оригінального архіву.

Каталоги — довідник і менеджер локальних записів; вибір матеріалу тут не змінює геометрію поточного CAD. Непідтримувані технологічні поля пропущено; висоту розміщення верхніх шаф задавайте в редакторі.

## JSON-поля і статуси

- `reviewStatus = illustrative`: демонстраційний запис.
- `reviewStatus = external_catalog`: зовнішня довідкова сторінка, не імпортований товар.
- `reviewStatus = unconfigured`: порожній виробничий профіль.
- `reviewStatus = draft`: користувацький / імпортований запис, що потребує перевірки.
- `manufacturingApproved = false`: заборона використовувати як єдине джерело під час виготовлення.

Уточнення: JSON-запис із `manufacturingApproved = true` **не є доказом** реальної виробничої придатності. Імпортер примусово переводить зовнішні записи до чернеток. Подальша реалізація має вести журнал: джерело, артикул, редакція документа, технолог-підписант, контрольний виріб і відгук постачальника.

## Для іншого застосунку

- JavaScript: `import {loadTechCatalogs,validateCatalog,productionReadiness} from './tech-data/tech-library.mjs'` (потребує сервера з JSON файлами).
- Python: `python tech-data/import_python.py` або імпортуйте `get_records`.
- Параметричні шаблони: `module-pack.json` із форматом `furnix.module.library` v1.
- **Немає** універсального прямого «вставити STEP/SKP/BXF» для довільного CAD-редактора. Потрібні адаптери геометрії та фурнітурних правил.

## Ресурси й авторські права

Дані в `tech-data/*.json`, код індексатора та 24 шаблони створені як оригінальний демонстраційний набір FURNIX. Посилання на сторонні бібліотеки не означають право вільно перепаковувати чи поширювати їхні файли. `Woodworking` — MIT, але потребує середовища FreeCAD; `OpenCutList` — GPLv3 і розрахований на SketchUp. Їхній код в архів **не** включено.
