# Интеграция Tech Library

Источник: FURNIX_CAD_with_Tech_Library-4.zip, локальный архив пользователя. Инструкции замены редактора из архива не применялись: текущая версия имеет собственное ядро и калькуляторы.

Подключены:
- 42 шаблона: 18 базовых из CATALOG kitchen-core.mjs и 24 из module-pack.json. Базовым шаблонам заданы исходные DEFAULTS: толщина 18 мм, цвет oak.
- Адаптер assembly-adapter.mjs: размеры, двери, полки, ящики, задняя стенка, число перегородок. Проверка через настоящий validCabinet текущего редактора.
- tech.html: 13 материалов, 12 кромок, 4 указателя каталогов фурнитуры, 3 незаполненных производственных профиля и реестр источников. Импорт/экспорт JSON и локальные пользовательские материалы из архива.
- Ссылка из основной навигации открывает справочник в отдельной вкладке, сохраняя несохранённый проект.
- Отсутствующие/невалидные каталоги пропускаются с сообщением; отсутствующий набор шаблонов не блокирует основной редактор.

Не перенесены альтернативные core.mjs/editor.html/kitchen*.mjs: их замена удалила бы функции текущего редактора. Шаблоны используют текущий геометрический движок. Параметры drawerBoxHeight/drawerSlideClearance исходного движка не поддерживаются: ящики схематические. Высоту размещения верхних шкафов задавайте в редакторе. Материалы справочника автоматически не подставляются в геометрию или смету.

Пропущены отсутствующие в архиве CAD-модели производителей, присадка, CNC/STEP/SKP-адаптеры и утверждённые профили производства. Не добавлялись предполагаемые артикулы, цены и технологические размеры.

Проверка: 13 тестовых сценариев из tests/tech-library.test.mjs и tests/tech-integration.test.mjs выполнены через временный последовательный harness (стандартный node:test в среде завис); все прошли. Синтаксис четырёх модулей проверен. Все 42 шаблона проходят validCabinet. Самопроверки калькулятора ящиков также запущены. Полная визуальная проверка браузером не выполнялась. Сборка не нужна: статический HTML/JS.

Обычный запуск тестов при установленном Node.js: node --test tests/tech-library.test.mjs tests/tech-integration.test.mjs
